# 📚 SkillsSphere — Course Discovery & Learning Platform

[![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://b13-a8-skill-sphere-alpha.vercel.app)

**SkillsSphere** is a web-based educational platform designed to help users discover, search, and explore structured skill-development courses seamlessly.

The platform focuses on offering a fast, responsive user interface combined with modern authentication and clean client/server component architecture in Next.js.

---

### ✨ Key Features

- 🔎 **Course Search & Filtering:** Filter courses by categories, skill levels, and keywords in real-time.
- 🔐 **Authentication System:** Integrated **Better Auth** supporting both Google OAuth and email/password login.
- ⚡ **Optimized Performance:** Built with **Next.js App Router** leveraging Server Components for fast initial page loads and SEO optimization.
- 📱 **Fully Responsive:** Styled with **Tailwind CSS** to deliver a smooth experience across mobile, tablet, and desktop viewports.

---

### 🛠️ Tech Stack

- **Framework:** Next.js (App Router), React
- **Language:** JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth (Google OAuth + Credentials)
- **Deployment:** Vercel
